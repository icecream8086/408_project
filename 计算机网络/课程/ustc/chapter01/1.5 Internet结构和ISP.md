# Internet 结构和 ISP（网络服务提供商）

## 1. 基本概念

- Internet是"网络的网络"
- 端系统通过ISP(Internet Service Providers)连接到互联网
  - 端系统(End System)：直接使用网络服务的设备，如计算机、手机、服务器等
- 接入ISP必须互联，使得任意两个端系统可以相互通信

## 2. ISP层次结构

### 2.1 三层ISP模型

1. **第一层ISP(Tier-1)**
   - 国家级/国际级覆盖，高速连接
   - 直接与其他第一层ISP相连
   - 例如：Level 3, Sprint, AT&T, NTT
   - 特点：分布广、节点有限、多重连接

2. **第二层ISP(区域ISP)**
   - 连接接入ISP和第一层ISP
   - 覆盖特定地理区域

3. **第三层ISP(接入ISP)**
   - 直接连接终端用户（住宅、公司、大学等）

### 2.2 内容提供商网络(ICP)

- 例如：Google, Microsoft, Akamai
- 特点：
  - 自建网络，将内容靠近用户
  - 提高服务质量，降低运营成本
  - 常使用专网绕过第一层ISP
    - 原理：
      1. 目的：减少数据传输跳数(数据包经过的网络节点数量)，降低延迟和成本
         - 每经过一个ISP节点称为一跳
         - 跳数越多，延迟和丢包风险越高
      2. 方式：自建骨干网+与下层ISP直接对等互联
      3. 优势：避免第一层ISP的高额传输费用
      4. 实现：在IXP建立对等连接，部署边缘服务器

## 3. ISP互联方式

1. **POP(Point of Presence)**
   - 高层ISP的客户接入点
   - 涉及费用结算
   - 多宿(Multi-home)：低层ISP接入多个高层ISP

2. **对等互联(Peering)**
   - 两个ISP直接连接
   - 通常不涉及费用结算
   - 通过Peering Link实现

3. **互联网交换点(IXP)**
   - 多个ISP对等互联的枢纽
   - 提高网络效率
   - 通常不涉及费用结算

## 4. 互联网结构特点

- 经济和国家政策驱动发展
- 分组传输需要经过多个网络
- 松散的层次结构
- 图论视角：
  - ISP可视为图中的节点
  - ISP间的连接关系构成图的边
  - 形成复杂的网络拓扑结构
  - 具有小世界网络特性(高度聚集、短路径)
