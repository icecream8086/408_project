# 修正后的 4 步时间复杂度计算框架

## 符号约定

- $n$：输入规模（问题大小）
- $i$（或 $x$）：**参与循环条件判断的变量**
- $i_k$：第 $k$ 次循环**开始前**变量 $i$ 的值（$k=0$ 为初始值）
- $k$：**已完整执行的循环次数**（初始 $k=0$）
- $t$：**总循环次数**（满足条件的最大 $k$ 值）

---

## 第 1 步：判断变量参与类型

- **类型 A**：循环变量参与条件判断 → 用递推法
- **类型 B**：循环变量不参与条件判断 → 直接计算

---

## 第 2 步：写出递推式（仅类型 A）

- **类型 A**：$i_{k+1} = f(i_k)$，$i_0 = \text{初始值}$
- **类型 B**：$t = \text{固定次数}$

---

## 第 3 步：解出循环次数 $t$

- **类型 A**：解通项 $i_k = g(k)$ → 代入终止条件 → 解出最大 $k$ → $t = k_{\max} + 1$
- **类型 B**：直接得 $t$

---

## 第 4 步：得到时间复杂度

$$
T(n) = O(t)
$$

**嵌套规则**：
- 内外独立 → 直接相乘
- 外层影响内层 → 内层用关于外层变量的函数求和

---

## `转换步骤`：指数与对数的互逆关系

**时间复杂度中的"指数取倒数"即取对数。**

| 运算方向 | 数学操作 | 复杂度意义 |
|---------|---------|-----------|
| $n \to 2^k$ | 取指数 | 问题规模爆炸（递归树节点数） |
| $2^k \to k$ | 取对数 | 求出循环/递归次数 $O(\log n)$ |

**公式对照**：
- $x^2 = a \iff x = a^{1/2}$（指数取倒数）
- $2^k = n \iff k = \log_2 n$（时间复杂度中的"倒算"）

当条件为 $2^k < n$，求 $k$ 就是在对指数"取倒数"。

---

## 应用示例 1（类型 A）

```c
x = 2;
while (x / n < 2)
    x = 2 * x;
```

| 变量 | 值 |
|-----|-----|
| $x_0$ | $2$ |
| 递推 | $x_{k+1} = 2x_k$ |
| 通项 | $x_k = 2^{k+1}$ |
| 条件 | $2^{k+1} < 2n \Rightarrow 2^k < n$ |
| 次数 | $t = \lceil \log_2 n \rceil$ |
| 复杂度 | $O(\log n)$ |

---

## 应用示例 2（类型 B × 依赖）

```c
for (i = 1; i * i <= n; i++)
    for (j = 1; j <= i; j++)
        count++;
```

| 层次 | 分析 |
|-----|------|
| 外层 | $i \le \sqrt{n}$，次数 $m = \lfloor \sqrt{n} \rfloor$ |
| 内层 | $j$ 从 1 到 $i$，次数 $= i$ |
| 总和 | $\sum_{i=1}^m i = \frac{m(m+1)}{2} \approx \frac{n}{2}$ |
| 复杂度 | $O(n)$ |

---

## 快速判断表

| 代码模式 | 类型 | 次数公式 |
|----------|------|----------|
| `for(i=1; i<=n; i++)` | B | $n$ |
| `for(i=1; i<=n; i*=2)` | A | $\log_2 n$ |
| `while(i<n) i+=c` | A | $n/c$ |
| `for(i=1; i<=n; i++) for(j=1; j<=n; j++)` | B×B | $n^2$ |
| `for(i=1; i<=n; i++) for(j=1; j<=i; j++)` | B×依赖 | $O(n^2)$ |
| `for(i=1; i*i<=n; i++) for(j=1; j<=i; j++)` | B×依赖 | $O(n)$ |
| `while(x<n) x*=2` | A | $\log_2 n$ |

---

## 易错点提醒

**内层变量不重置**：
```c
for (i=1; i<=n; i++)      // 外层 n 次
    while (x < n)         // 内层总共 O(log n) 次
        x = 2*x;
```
→ 总复杂度 $O(n + \log n) = O(n)$，而非 $O(n \log n)$

---

## 总结

1. **区分类型**：变量是否参与条件判断
2. **类型 A 写递推**：找 $i_{k+1}$ 与 $i_k$ 的关系
3. **解次数 $t$**：通项 → 不等式
4. **得复杂度**：$O(t)$，嵌套时注意变量重置
5. **数学直觉**：对数复杂度就是指数过程的"逆运算"
