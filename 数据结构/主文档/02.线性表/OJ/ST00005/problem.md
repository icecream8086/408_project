# 背景  

单链表是用链式存储方式实现的线性表。插入操作是单链表的基本操作之一，包括按位序插入、后插操作和前插操作。

# 描述  

实现带头节点的单链表的按位序插入操作。给定一个带头节点的单链表，在第 i 个位置（1 ≤ i ≤ 链表长度+1）插入元素 e。如果插入成功，返回 true；如果插入位置不合法，返回 false。

# 格式

## 输入  

第一行包含三个整数：n, i, e，分别表示链表的当前长度、插入位置和要插入的元素。
第二行包含 n 个整数，表示链表的当前元素（从头节点的下一个节点开始）。

## 输出  

如果插入成功，输出 "true"。
如果插入失败，输出 "false"。

# 样例

```input1
5 3 99
10 20 30 40 50
```

```output1
true
```

```input2
5 8 99
10 20 30 40 50
```

```output2
false
```

# 限制  

每个测试点：时间 1 秒，内存 1024 KiB。
最大链表长度：100
元素值范围：-1000 ≤ 元素值 ≤ 1000
假设链表已带头节点初始化
