# 背景  

单链表的建立主要有尾插法和头插法。尾插法将新节点插入到链表尾部，适合顺序建立链表。

# 描述  

使用尾插法建立带头节点的单链表。给定一系列整数（以-1结束），使用尾插法建立单链表，并输出链表中的所有元素。

# 格式

## 输入  

一行包含多个整数，以-1结束。例如：10 20 30 40 50 -1

## 输出  

建立链表后，输出链表中的所有元素（从头节点的下一个节点开始），用空格分隔。

# 样例

```input1
10 20 30 40 50 -1
```

```output1
10 20 30 40 50
```

```input2
-1
```

```output2

```

# 限制  

每个测试点：时间 1 秒，内存 1024 KiB。
最大元素数量：100
元素值范围：-1000 ≤ 元素值 ≤ 1000
