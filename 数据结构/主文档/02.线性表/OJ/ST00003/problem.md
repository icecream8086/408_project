# 背景  

顺序表是线性表的一种存储结构，通过连续的存储单元存储数据元素。查找操作是顺序表的基本操作之一，包括按位查找和按值查找。

# 描述  

实现顺序表的按值查找操作。给定一个顺序表 L（用数组表示），表长度 n，查找元素 e 在顺序表中的位置。如果找到，返回 true 并输出元素的位置（位序，从1开始）；如果未找到，返回 false。

# 格式

## 输入  

第一行包含两个整数：n, e，分别表示顺序表的当前长度和要查找的元素。
第二行包含 n 个整数，表示顺序表的当前元素。

## 输出  

如果找到元素，第一行输出 "true"，第二行输出元素的位置（位序，从1开始）。
如果未找到元素，只输出一行 "false"。

# 样例

```input1
5 30
10 20 30 40 50
```

```output1
true
3
```

```input2
5 99
10 20 30 40 50
```

```output2
false
```

# 限制  

每个测试点：时间 1 秒，内存 1024 KiB。
最大表长度：1000
元素值范围：-10000 ≤ 元素值 ≤ 10000
