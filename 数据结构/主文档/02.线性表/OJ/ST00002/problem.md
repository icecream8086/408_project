# 背景  

顺序表是线性表的一种存储结构，通过连续的存储单元存储数据元素。删除操作是顺序表的基本操作之一。

# 描述  

实现顺序表的删除操作。给定一个顺序表 L（用数组表示），表长度 n，删除第 i 个位置（1 ≤ i ≤ n）的元素。如果删除成功，返回 true 并输出被删除的元素和更新后的顺序表；如果删除位置不合法，返回 false。

# 格式

## 输入  

第一行包含两个整数：n, i，分别表示顺序表的当前长度和要删除的位置。
第二行包含 n 个整数，表示顺序表的当前元素。

## 输出  

如果删除成功，第一行输出 "true"，第二行输出被删除的元素，第三行输出删除后的顺序表元素（用空格分隔）。
如果删除失败，只输出一行 "false"。

# 样例

```input1
5 3
10 20 30 40 50
```

```output1
true
30
10 20 40 50
```

```input2
5 8
10 20 30 40 50
```

```output2
false
```

# 限制  

每个测试点：时间 1 秒，内存 1024 KiB。
最大表长度：1000
元素值范围：-10000 ≤ 元素值 ≤ 10000
