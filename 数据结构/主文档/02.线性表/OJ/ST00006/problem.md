# 背景  

单链表的查找操作包括按位查找和按值查找。按位查找通过检查节点位置来查找特定节点，而按值查找通过比较节点值来查找特定节点。

# 描述  

实现带头节点的单链表的按值查找操作。给定一个带头节点的单链表，查找元素 e 在链表中的位置（位序，从1开始）。如果找到，返回位置；如果未找到，返回 -1。

# 格式

## 输入  

第一行包含两个整数：n, e，分别表示链表的当前长度和要查找的元素。
第二行包含 n 个整数，表示链表的当前元素。

## 输出  

一个整数，表示元素的位置（从1开始）。如果未找到，输出 -1。

# 样例

```input1
5 30
10 20 30 40 50
```

```output1
3
```

```input2
5 99
10 20 30 40 50
```

```output2
-1
```

# 限制  

每个测试点：时间 1 秒，内存 1024 KiB。
最大链表长度：100
元素值范围：-1000 ≤ 元素值 ≤ 1000
